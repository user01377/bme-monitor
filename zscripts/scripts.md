
## Development Scripts

This directory contains development and helper scripts used for testing, local development, and debugging.

| Script                  | Description                                                                                      |
| ----------------------- | ------------------------------------------------------------------------------------------------ |
| `seed-test.py`        | Seeds the PostgreSQL database with test data.                                                    |
| `seed_test_device.py` | Inserts a test device into the`data-receiver` for local development.                           |
| `gen-payload.py`      | Generates test payloads for validating hashing and authentication logic in the`data-receiver`. |
